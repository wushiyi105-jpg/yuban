# UI 说明：语伴

- **谁在什么时刻打开**：给常写英文工作邮件的人。
- **首屏任务句**：这句英文，问题在哪。
- **主操作**：按「贴英文段落 → 看硬错与语气 → 生成复练题」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：双栏批改本；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：双栏批改本。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给常写英文工作邮件的人：逐句指出问题，保留原片段，标明是语法、语气还是可选风格；反复出现的两三个问题会变成你的复练题。
